## 3. Code-Based Ability System

Codes: Heart, Word, Friendship, Dream, Legacy, Joy, Confidence, Calm, Oasis, Insight.

Ability categories: Pulse Abilities, Aura Abilities, Shift Abilities, and Code Abilities.

## 4. Villain Lore

### The Scribblers
Word-stealing imps born from corrupted Word Code. Abilities: Word Theft, Scribble Storm, Ink Warp. Weakness: Heart Code.

### The Fog
Emotion cloud manifested from unresolved emotions. Abilities: Emotion Drain, Confusion Field, Mood Shift. Weakness: Heart Pulse.

### The Silence
Lost voice entity originating from broken Confidence Code. Abilities: Voice Lock, Quiet Zone, Echo Break. Weakness: Confidence Code.

## 5. Cross-World Rules

1. Tier Compatibility: T1–2 Urban; T3 Code; T4 Legendary; T5 Cosmic.
2. Alignment Fit: Loyal characters need protection in Undead worlds; Chaotic characters can disrupt Code worlds; Legacy characters can enter any world.
3. Code Relevance: A character's Code must matter in the target world.
4. Canonical Identity: A game may adapt presentation and mechanics, but core identity, tier, alignment, and lore remain canonical.

## 6. Visual Guide

Visual categories: Mascot Style for Kotton/Kimba/Jada; Urban Hero Style for Zavione; Fantasy Style for Doughboys; Puzzle Adventure Style for Tricia; Villain Style for Scribblers/Fog/Silence.

Visual elements include color palettes, silhouette shapes, signature accessories, Code symbols, and Tier auras.

## Canonical Character Record

Every character record should support: Name, Species, Tier, Alignment, Signature Code, Abilities, Weaknesses, Universe Role, Cross-Game Compatibility, Visual Style, Voice & Personality, Lore Summary, and versioned canon status.
