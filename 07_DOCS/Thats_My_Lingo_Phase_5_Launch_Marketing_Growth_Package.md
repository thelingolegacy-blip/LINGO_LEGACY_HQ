## Vercel deployment and launch fit

- Vercel can host the public web landing page and HTML5 web build with preview and production deployments.
- Vercel Functions can support launch pages, lightweight web APIs, referral landing flows, and non-Firebase endpoints.
- Vercel Cron Jobs can support scheduled campaign summaries, report exports, and operational reminders.
- Vercel Blob can store generated marketing kits, reports, screenshots, trailers, and downloadable press assets.
- Vercel Web Analytics and Speed Insights can track launch page traffic, campaign landing pages, and Core Web Vitals.
- Firebase can remain the game backend for auth, Firestore state, Cloud Functions, Storage, Remote Config, and game analytics where retained.
