# Kotton's Code — Studio-Grade Cartoon World Bible

## Canon

**Kotton's Code** is a premium children's story universe spanning books, animated YouTube episodes, TikTok/short-form episodes, interactive games, educational experiences, and future merchandise.

Kotton is a fluffy Maltese dog who loves pancakes. Canon birthday: **August 11, 2021**.

## Creative north star

The world must feel like a real animated franchise—not a children's landing page with disconnected assets.

Target qualities:

- warm, cinematic, playful
- premium 2D/3D hybrid potential
- expressive character animation
- consistent character proportions and voices
- safe-for-children storytelling
- strong emotional learning
- recognizable locations and recurring visual motifs
- episode-to-book continuity
- short-form moments that naturally lead into full episodes/books

## World architecture

The cartoon world is organized into connected locations rather than one static background:

1. **Kotton's Home** — family, routines, breakfast, pancakes, emotional safety
2. **The Code Room** — visualizes learning, clues, XP, discoveries, and problem solving
3. **Pancake Corner** — recurring food/comedy/social location
4. **The Glittering Paw Boutique** — Book 2 setting; sensory-rich environment used to explore social anxiety/sensory overload themes
5. **Lingo Lane** — neighborhood hub connecting characters and adventures
6. **Legacy Learning Garden** — outdoor discovery, science, nature, and emotional-regulation stories
7. **Adventure District** — episodic mystery/exploration location
8. **Story Stage** — meta location for musical, holiday, and audience-participation specials

Locations should support reusable camera angles, lighting states, props, background variants, and seasonal dressing.

## Story engine

Every episode follows a flexible structure:

`HOOK → DISCOVERY → PROBLEM → FEELING → CODE/CLUE → TRY → CONSEQUENCE → SOLUTION → REFLECTION → NEXT ADVENTURE`

The Code is a storytelling mechanic, not merely a points system. It represents learning, curiosity, kindness, communication, problem solving, and progress.

## Book continuity

### Book 1 — Kotton's First Words

32-page children's book and foundational canon entry. The book should become an adaptable story asset for animation, narration, classroom/parent companion content, and short-form clips.

### Book 2 — Kotton's Code: The Case of the Shaking Shadow

Theme: overcoming sensory overload/social anxiety. Setting: The Glittering Paw Boutique. Ages 4–8.

Future books should feed the same character, location, emotional-learning, and Code continuity system.

## YouTube series

YouTube is the long-form home of the animated universe.

### Episode package

Each episode should have:

- episode premise
- age/learning objective
- script
- storyboard
- shot list
- character list
- location list
- dialogue/voice plan
- music/SFX plan
- animation notes
- title
- thumbnail brief
- description
- chapters where appropriate
- parent/educator context when appropriate
- accessibility/caption plan
- final QA checklist

### Content ladder

`BOOK → FULL EPISODE → SHORT CLIPS → SHORTS → BTS/CREATOR CONTENT → COMPANION ACTIVITY`

The same canonical story should generate multiple formats without producing contradictory lore.

## TikTok / short-form series

TikTok is an actual storytelling channel, not only an advertising channel.

Short-form formats:

- 15–30 second character moments
- 30–60 second mini-adventures
- Code clues
- pancake comedy
- character reactions
- emotional-learning moments
- cliffhangers
- audience questions
- behind-the-scenes animation
- book-to-screen comparisons
- recurring series formats

Each short should have a hook in the opening seconds, one clear emotional/story beat, captions, safe audio choices, and a next-step CTA.

## Production quality gates

### Story gate

Canon, age appropriateness, emotional clarity, and educational objective approved.

### Visual gate

Character consistency, environment continuity, composition, readability, and animation quality approved.

### Audio gate

Voice consistency, dialogue clarity, music/SFX balance, captions, and child-safe audio approved.

### Platform gate

YouTube/TikTok dimensions, captions, thumbnails, metadata, rights, and platform-specific packaging approved.

### Safety gate

No unsafe instructions, inappropriate material, exploitative content, or misleading child-directed claims.

## Franchise rule

A book is not a separate project from the cartoon. A YouTube episode is not separate from TikTok. Games, books, video, and merchandise all belong to one canonical Kotton's Code universe.

`ONE CANON → MANY FORMATS → MANY PLATFORMS → ONE KOTTON'S CODE WORLD`
