Execution order

A gated delivery sequence designed to avoid duplicate work and production regressions.

  1. Reconcile. Assign owners and ACTIVE / MERGE / REFERENCE / ARCHIVE status for every repository.
  2. Repair. Review existing PRs before opening overlapping changes; fix deterministic source defects.
  3. Execute. Run local and CI checks on a trusted, eligible runner; retain logs and artifacts.
  4. Verify. Independently correlate commit, run, job, runner, artifact hashes, security, and QA.
  5. Authorize. Human approval remains separate from tests, merges, deploys, and production promotion.
