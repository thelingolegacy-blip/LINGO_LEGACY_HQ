Technical Stack

  • Next.js, TypeScript, and Tailwind CSS on Vercel
  • Vercel Functions, Cron Jobs, Blob, Web Analytics, Speed Insights, and AI Gateway
  • Neon via the Vercel Marketplace for relational data; Vercel Postgres is no longer first-party and existing databases were migrated in December 2024
  • Upstash Redis via the Vercel Marketplace for queues and cache; Vercel KV is no longer first-party and existing stores were migrated in December 2024
  • Firebase can remain for intentionally retained authentication, Firestore, or Cloud Functions workloads while Vercel serves the frontend and deployment layer
