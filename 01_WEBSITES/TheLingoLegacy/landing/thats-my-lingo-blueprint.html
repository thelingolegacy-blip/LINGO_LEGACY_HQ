Scene Flow

  • Splash Screen: Lingo Legacy logo, That's My Lingo logo, loading animation.
  • Main Menu: Play, Rewards, Shop, Leaderboard, Profile, Settings.
  • Slot Room: tokens, XP level, reels, bet controls, spin, free spins, bonus, jackpot.
  • Bonus and Reward scenes for special events, prize reveals, and daily rewards.

Backend and Deployment

  • Firebase for authentication, player profiles, cloud save, rewards, leaderboards, analytics, and remote configuration.
  • Vercel for the HTML5 web build, preview deployments, production deployment, and Vercel Functions where server-side game APIs are needed.
  • Vercel Blob can store generated exports, reports, and non-critical media packages; immutable asset URLs are preferred for production cache behavior.
  • Vercel Web Analytics and Speed Insights can track site traffic and Core Web Vitals for the web build.
