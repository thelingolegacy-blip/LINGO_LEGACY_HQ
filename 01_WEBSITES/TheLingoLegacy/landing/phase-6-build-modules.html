Vercel Production Foundation

  • Vercel project, preview deployments, production deployments, Vercel Functions, and Cron Jobs.
  • Vercel Blob for uploads, exports, media files, generated assets, and reports.
  • Vercel AI Gateway for Ask Lingo model routing and AI tool orchestration.
  • Vercel Web Analytics and Speed Insights for traffic, engagement, and Core Web Vitals.
  • Neon via the Vercel Marketplace for relational data; Vercel Postgres is no longer first-party and existing databases were migrated in December 2024.
  • Upstash Redis via the Vercel Marketplace for cache, queues, rate limits, and workflow state; Vercel KV is no longer first-party and existing stores were migrated in December 2024.
