Vercel Production Foundation

  • Next.js frontend deployed on Vercel
  • Vercel Functions for APIs and admin operations
  • Vercel Cron Jobs for scheduled reminders, summaries, and syncs
  • Vercel Blob for documents, reports, generated files, and media uploads
  • Vercel AI Gateway for Ask Lingo model routing
  • Vercel Web Analytics and Speed Insights for traffic and Core Web Vitals
  • Neon via the Vercel Marketplace for relational data; Vercel Postgres is no longer first-party and existing databases were migrated in December 2024
  • Upstash Redis via the Vercel Marketplace for queues and short-lived workflow state; Vercel KV is no longer first-party and existing stores were migrated in December 2024

Financial, identity, admin, and AI automation actions should require explicit permissions, audit logs, revocable access, and manual approval for high-risk operations.
