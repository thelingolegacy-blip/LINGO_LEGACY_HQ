Vercel + Firebase Deployment

  • Vercel for HTML5 web build, preview deployments, and production releases.
  • Vercel Functions for web/API routes that are not Firebase-native.
  • Vercel Cron Jobs for scheduled reports and non-Firebase syncs.
  • Vercel Blob for reports, generated exports, and marketing/download packages.
  • Vercel Web Analytics and Speed Insights for web traffic and Core Web Vitals.
  • Firebase for auth, Firestore game state, Cloud Functions, Storage, Remote Config, and Firebase Analytics where retained.
