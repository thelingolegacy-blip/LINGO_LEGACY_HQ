Production Timeline

The rollout moves from static launcher foundation to playable worlds, multiplayer expansion, mobile, smart TV, and creator marketplace.

Phase 1 — Weeks 1-4

Website shell, Cloudflare and Vercel setup, game launcher, Lingo ID, asset pipeline, and first playable scaffolds.

Phase 2 — Months 2-4

Launch That’s My Lingo and Kotton’s Code with characters, soundtracks, animations, levels, UI, saves, and rewards.

Phase 3 — Months 5-8

Add Legacy Zombies, Spades, UhOh University, Lingo City, expanded leaderboards, economy, and cross-game items.

Phase 4 — Months 9-12

Add multiplayer, smart TV support, mobile apps, community events, creator marketplace, and live-service operations.
