Visual hierarchy

The map owns the full screen. Floating glass controls sit above it: top weather and health, right-side 2D/3D and recenter controls, and a bottom control hub in the thumb zone.

Status markers

Glowing blue means watering, amber means pending or scheduled, green means active or healthy, and red means alert. Detail appears progressively as the user zooms.

Interaction motion

Pinch, pan, tap, and swipe interactions use soft inertia, marker pulses, slide-up detail cards, and full-map digital ripples when a scene activates.

Event-driven realtime architecture

Field Hardware

MQTT devices

Sprinklers, light drivers, valves, and soil sensors publish telemetry and receive commands on estate-scoped topics with QoS 0 for frequent telemetry and QoS 1 for critical control.

Cloud Backend

Broker and bridge

An MQTT broker feeds a Node.js app server, which stores latest state in Redis and streams JSON updates to the mobile UI over WebSockets.

Mobile App UI

Live map rendering

The portal receives marker updates, animates pulses, and sends homeowner actions back to the backend for authorization before hardware commands are published.
